# RC10.3 UI Scope Hotfix

`Ui.showModalDialog()` requires:

`https://www.googleapis.com/auth/script.container.ui`

RC10.3 adds this scope to `appsscript.json`.

## Apply
This release changes BOTH:
- `Code.gs`
- `appsscript.json`

After replacing the manifest, reload the spreadsheet and authorize the newly requested permission when prompted.
